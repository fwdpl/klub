# Pomysły spoza zakresu

Pomysły zgłoszone w trakcie pracy, które nie należą do bieżącego etapu. Nie implementujemy ich bez decyzji Jacka.

- Przypomnienie (push) o zbliżającym się terminie wpłaty na wyjazd – do decyzji Jacka (5.11.2026).
- Push „nowe zadanie na checkliście” wysyłany automatycznie po imporcie – zależy od otwartej decyzji o wysyłce pushy (SPEC §8); na razie po imporcie jest propozycja ręcznej wysyłki (27.11.2026).
- Automatyczny import checklisty z repozytorium (katalog inbox/ + GitHub Actions) (27.11.2026).
- Szablony checklist kopiowane z poprzedniego wyjazdu (27.11.2026).
